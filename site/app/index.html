アプリのように使う

ホーム画面に追加すると、アイコンを押すだけで開けて、アドレスバーのない全画面で見られます。アプリストアからのインストールや会員登録は要りません。無料です。

iPhone・iPad

  1. Safari で kyochika.jp をひらく
  2. 画面の下（iPad は上）にある共有ボタン（四角から矢印が上に出ている形）を押す
  3. 出てきた一覧を上に送って「ホーム画面に追加」をえらぶ
  4. 右上の「追加」を押す

Chrome を使っているときも、共有ボタンから同じように追加できます。

Android

  1. Chrome で kyochika.jp をひらく
  2. 右上の「︙」を押す
  3. 「ホーム画面に追加」または「アプリをインストール」をえらぶ
  4. 「追加」または「インストール」を押す

パソコン（Chrome・Edge）

  1. kyochika.jp をひらく
  2. アドレスバーの右はしに出るインストールのボタンを押す

追加したあと

ホーム画面に黒い「キ」のアイコンができます。出発する駅は一度えらぶと次からも覚えています。催しの情報は、ひらくたびに新しいものを読みこみます。

やめるとき

アイコンを長押しして「削除」をえらぶだけです。ほかに消すものはありません。
