Lokakarya Anak: Penyangga Buku dari Kardus (Perpustakaan Ishihama)

Judul bahasa Jepang: ワークショップ石浜工房 こども向け「ダンボールブックスタンド」（石浜図書館）

Perpustakaan Ishihama lantai 4 (Stasiun Minami-Senju)
