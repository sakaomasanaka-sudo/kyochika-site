Pertunjukan Boneka (Perpustakaan Ishihama)

Judul bahasa Jepang: 人形劇公演（石浜図書館）

Pusat Pelatihan Industri Taito, lantai 3 (Stasiun Minami-Senju)

Pertunjukan boneka oleh rombongan profesional, diadakan Perpustakaan Ishihama. Pukul 11.00 dan 13.00, 70 kursi per sesi; tiket nomor di konter lantai 3.
