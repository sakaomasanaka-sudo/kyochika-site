■ サーバーに置く
  このフォルダの中身を、フォルダの形のまま、kyochika.jp の公開フォルダの直下に置きます。
  index.html が公開フォルダの直下に来るようにしてください。
  ページの中のリンクは「/」から始まる書き方なので、公開フォルダの直下以外に置くと表示がくずれます。

■ 公開したあとにやること
  1. サーバーの管理画面で、kyochika.jp の無料SSL（https）を有効にする。
  2. 連絡先に載せた info@kyochika.jp を、サーバーのメール設定で作る（作るまで届きません）。
  3. Google Search Console に kyochika.jp を登録し、sitemap.xml を送信する。
  4. 主催者からの登録を受けつけるなら、Googleフォームなどを作り、そのURLを config.js の registerUrl に入れる。

■ 催しの更新
  催しごとのページや一覧は、data.js からまとめて作りなおしています。
  data.js だけを書きかえても、トップページのさがす部分にしか反映されません。
  更新するときは、作りなおした一式をまるごと置きかえてください。
  いま入っているのは 2026年10月8日〜18日ごろの 134件（美術展47、ライブ42、フード15、マーケット15、祭り9、ポップアップ6）。うち16件はインスタグラムの告知からです。週に1回は更新が必要です。
